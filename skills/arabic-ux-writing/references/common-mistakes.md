## Hamza

Cutting hamza (written) and joining hamza (not written) are the most frequent spelling errors in interfaces.

| Wrong | Right | Rule |
|---|---|---|
| الى، او، ان، اذا | إلى، أو، أنّ / إنّ، إذا | Particles take a written hamza |
| الاعدادات، انشاء، الغاء، ارسال، اضافة | الإعدادات، إنشاء، إلغاء، إرسال، إضافة | Verbal nouns of four-letter verbs (أفعل): hamza below |
| ادخل، ارسل، اضف، اكمل | أدخل، أرسل، أضف، أكمل | Imperatives of four-letter verbs: hamza above |
| إسم، إبدأ، إختر، إستخدام، الإشتراك، الإنتظار، إنتهى | اسم، ابدأ، اختر، استخدام، الاشتراك، الانتظار، انتهى | No hamza: nouns like اسم، ابن، اثنان; three-letter imperatives; five- and six-letter verbs and their verbal nouns |
| مسؤل، مسئول | مسؤول | |
| تاكيد، تاريخ الانشاء | تأكيد، تاريخ الإنشاء | Medial hamza is written |
| إنشاء الله | إن شاء الله | Three words |
| شيئ | شيء | |
| قراءه | قراءة | |

A quick test for an initial alef: say the word after «و». If the alef sound survives («وأَرسل»), it is a cutting hamza and is written. If it disappears («واستخدم»), it is not written.

## Taa marbuta and haa

A feminine ending takes its two dots.

| Wrong | Right |
|---|---|
| كلمه المرور، صفحه، رساله، قائمه | كلمة المرور، صفحة، رسالة، قائمة |
| اضغط علية، هذة | اضغط عليه، هذه |

Test: if the ending is pronounced "t" when you continue to the next word, it is «ة».

## Alef maqsura and yaa

| Wrong | Right |
|---|---|
| فى، الذى، التى، يدوى | في، الذي، التي، يدوي |
| الي، علي (preposition)، حتي، مستوي | إلى، على، حتى، مستوى |

Writing final yaa without dots is a regional print habit; in interface text write the dots.

## Tanween

- Tanween fatha sits on the letter before the alef: «شكرًا»، «مرحبًا»، «مجانًا»، «تلقائيًا». Not on the alef («شكراً») in careful typography, though that form is widespread; choose one and apply it everywhere.
- No alef after taa marbuta or after hamza preceded by alef: «مرةً»، «مساءً».
- «جارٍ التحميل», not «جاري التحميل». «تسجيل دخولٍ» needs no mark at all: do not add tanween where nothing is ambiguous.

## Attached words and spacing

| Wrong | Right | Rule |
|---|---|---|
| و الإعدادات | والإعدادات | «و» joins the next word |
| ب البريد، ل المستخدم | بالبريد، للمستخدم | One-letter prepositions join |
| لل المستخدم، لالمستخدم | للمستخدم | «لـ» plus «ال» |
| مرحبا ، كيف | مرحبًا، كيف | No space before punctuation |
| ما ذا، إن شاءالله | ماذا، إن شاء الله | |
| أن لا (after أن of purpose) | ألّا | |

## Other spelling traps

- «ذلك»، «هذا»، «لكن» have no written alef.
- «مئة» is the modern spelling; «مائة» is the older one. Pick one.
- «اللغة»، «الليلة», words beginning with lam keep both lams after the article; «للّغة» after «لـ».
- «ض» and «ظ»: «ضغط»، «ضبط»، «حفظ»، «نظام»، «انتظار»، «ملاحظة».
- «أيقونة»، «إنترنت»، «تكنولوجيا» / «تقنية»: fix one spelling for each loanword in the term list.
- Numbers as words: «ثلاثة أيام» but «ثلاث ساعات» (three to ten take the opposite gender of the counted noun). When unsure, use digits.
- Do not type Persian «ی» or «ک» in Arabic text; they look similar and break search. The Arabic letters are «ي» and «ك».

## Calques from English

| Translated-sounding | Natural | Why |
|---|---|---|
| قم بإدخال كلمة المرور | أدخل كلمة المرور | «قام بـ» plus a verbal noun pads every instruction |
| تم حفظ الملف بنجاح | حُفظ الملف | «تمّ» plus «بنجاح» is a double filler |
| الحساب الخاص بك | حسابك | Arabic has possessive suffixes |
| هل أنت متأكد أنك تريد الحذف؟ | حذف العنصر؟ | Ask about the action, not the user's certainty |
| انقر هنا للمزيد | اعرف المزيد عن الباقات | Links describe their destination |
| من فضلك انتظر | لحظات… / جارٍ التحميل… | "Please" on every line reads as translation |
| لا تتردد في التواصل معنا | تواصل معنا | Idiom carried over word for word |
| يمكنك أن تقوم بتغيير الإعدادات | يمكنك تغيير الإعدادات | Stacked auxiliaries |
| تم إرساله بواسطة أحمد | أرسله أحمد | Arabic avoids the agent-passive |
| كمستخدم جديد | بصفتك مستخدمًا جديدًا | «كـ» for role is an English "as" |
| بشكل تلقائي، بشكل سريع | تلقائيًا، بسرعة | «بشكل» plus adjective copies "-ly" |
| في حالة إذا كان | إذا | Double conditional |
| المزيد من المعلومات | معلومات أكثر / تفاصيل | |
| عدد 5 ملفات | 5 ملفات | |
| أكثر من أي وقت مضى، يلعب دورًا، على الرحب والسعة | rewrite the thought | Stock translated idioms |
| لقد قمنا بإرسال | أرسلنا | «لقد» adds weight interfaces do not need |
| العنصر غير متوفر حاليًا في هذا الوقت | العنصر غير متاح حاليًا | Redundancy |

Signs that a whole string needs rewriting rather than patching: it follows English word order clause by clause; it has three or more nouns in a row joined by «الخاص بـ»; it uses «الذي» / «التي» twice; it would not be said aloud by an Arabic speaker explaining the same thing.

## Agreement

- Non-human plurals take feminine singular agreement: «الملفات المحذوفة»، «هذه الإعدادات»، «البيانات محفوظة». Not «الملفات المحذوفون», not «البيانات محفوظ».
- Adjectives follow the noun and match it in definiteness: «رسالة جديدة»، «الرسالة الجديدة».
- In a construct (إضافة) only the last word takes the article: «إعدادات الحساب», not «الإعدادات الحساب».
- Dual forms exist and are expected: «ملفان»، «خطوتان»، «كلمتا المرور».
- A status label must agree with the thing it describes: «الطلب مكتمل»، «المهمة مكتملة». A shared status string used for both masculine and feminine objects needs a neutral form («تم الإكمال») or two strings.

## Consistency checks

Search the full string set for each pair and keep only one side:

- لوحة المعلومات / لوحة التحكم
- تنزيل / تحميل (for download)
- تسجيل الدخول / الدخول / دخول
- حذف / إزالة / مسح (for the same action)
- إعدادات / ضبط / تفضيلات
- بريد إلكتروني / إيميل
- موقع / موقع إلكتروني / ويب سايت
- رمز / كود (for the same thing)
- Tanween style: «شكرًا» / «شكراً»
- Digit system: 0-9 / ٠-٩
- Address: «أدخل» (imperative) / «إدخال» (verbal noun) on the same kind of element

## Proofreading order

1. Terms: one rendering per concept.
2. Hamza, taa marbuta, alef maqsura.
3. Punctuation and attached particles.
4. Calques and filler.
5. Agreement, especially around variables.
6. Read each screen aloud once. Anything you would not say, rewrite.
